## Scientific conventions

Exposure normalization rescales each included frame by `reference_exposure / frame_exposure` before the selected stack estimator is applied. This makes robust estimators usable on mixed-integration-time data. The exposure-weighted mean then weights those normalized frames by integration time.

The input correction-state selector is documentary/safety metadata; it does not silently apply or remove detector corrections. Dark and flat correction remain optional controls in the Corrections tab.

ROI shapes and layer-line overlays are annotations/analysis constructs only. They do not modify the quantitative detector image.

Layer-line profile sampling uses interpolation only for analysis extraction. It does not rotate or resample the corrected TIFF.

## Validation

Synthetic tests cover mixed-exposure stacking, layer-line spacing recovery, overlapping multi-peak fitting, ROI measurements, scaled image comparison and session round-tripping.
