# XRD Image Toolkit 0.7.1 — Exposure Metadata and Selection Reliability

## Exposure-aware file table

The file-selection table now distinguishes the **selected exposure** from detector-header diagnostics. It shows:

- selected exposure in seconds
- selected source (`filename`, `manual`, CSV, or confirmed header)
- detector-header exposure when available
- QC state (`OK`, `MANUAL`, `HEADER ONLY`, `NEEDS VALUE`, or `MISMATCH`)

## Filename parsing

Only explicit time tokens are accepted. Examples:

```text
S1_3_5s_S030_0_10.tif     -> 5 s
S1_3_10s_S031_0_00.tif    -> 10 s
S1_3_500ms_S032_0_00.tif  -> 0.5 s
S1_3_S029_0_01.tif        -> unknown
```

Tokens without units, including scan/frame identifiers such as `S029`, `_0_`, and `_01`, are ignored.

## Rayonix / MarCCD diagnostics

The private MarCCD frame header is read when present. `integration_time` and `exposure_time` are retained as diagnostic values. They are not trusted automatically under the default policy because acquisition filenames and detector headers can disagree.

Default policy: `filename only`. Alternative user-selectable policies are `filename → header` and `header → filename`.

When an included frame has a filename/header mismatch and exposure normalization is enabled, stacking asks for confirmation before proceeding.

## Manual exposure workflow

- set one or many selected files
- set all files
- enter seconds or milliseconds
- clear manual/CSV/session overrides
- re-detect filename/header candidates
- explicitly confirm the detector-header exposure for selected rows
- import exposure values from CSV

Manual and CSV values override automatic parsing.

## Multi-selection

The file tree now implements explicit desktop selection behavior:

- click: select one
- Ctrl+click: toggle individual rows
- Shift+click: select an anchor-to-clicked range
- Ctrl+Shift+click: add an anchor-to-clicked range without clearing the existing selection

This is especially useful for batch exposure assignment and include/exclude operations.

## Provenance

Stack frame reports and detector-coordinate provenance now retain the selected exposure source together with filename/header candidates and mismatch status.
