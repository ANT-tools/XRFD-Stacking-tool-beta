# XRD Image Toolkit 0.7.2 — Scrollable Control Tabs Hotfix

## Fixed

Large control tabs could extend below the visible desktop area, making lower controls inaccessible because notebook pages had no vertical scrollbar.

Version 0.7.2 makes every control tab vertically scrollable:

- Stacking
- Corrections
- Spatial Filters
- Contrast
- Symmetry
- Fiber Analysis
- Layer Lines
- ROI / Shapes
- Compare
- Performance
- Export

Each tab now has a visible vertical scrollbar. Mouse-wheel/trackpad scrolling is routed to the control tab whenever the pointer is over any widget inside that tab, including entries, labels, buttons, and section frames. The content width remains locked to the visible control pane, so only vertical scrolling is introduced.

## Scientific behavior

This is a GUI-layout hotfix only. No numerical processing, stacking, exposure normalization, detector-coordinate handling, layer-line fitting, ROI measurement, comparison calculations, or provenance logic was changed.
